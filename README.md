SparkPrompt is a browser-only productivity workspace. It gives developers and everyday users better prompts plus quick tools for daily writing and thinking.

## Start locally on Windows

1. Double-click START.bat.
2. Your browser opens at http://127.0.0.1:8000.
3. Sign in with any email and password, or choose Guest.
4. When finished, double-click STOP.bat.

Python 3 must be installed and available as py or python.

## Included features

- Local-only login and guest access
- Role-aware prompt generator with output and depth controls
- Quick Summary, Email Helper, Code Clarity, and Idea Spark tools
- Prompt recipes, local history, save, copy, rework, light/dark theme, and keyboard shortcut
- No passwords or work content are sent to a server
